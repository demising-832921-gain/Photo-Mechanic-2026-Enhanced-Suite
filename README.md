## Frequently Asked Questions (FAQ)

**Q: Does this tool modify my Photo Mechanic installation or core files?**
A: No. The Enhanced Suite operates as a separate companion application. It communicates with Photo Mechanic through its public interface and does not alter the core application files, ensuring stability.

**Q: I have Photo Mechanic version 5. Will this work?**
A: Yes. The suite is designed to be compatible with both Photo Mechanic 5 and the latest Photo Mechanic 6 releases. The installer will detect your version automatically.

**Q: Where are my saved profiles and settings stored?**
A: Your custom settings, templates, and profiles are saved in a dedicated folder within your user Documents directory (`Documents\PhotoMechanicEnhanced2026`). This makes backing up your configurations simple.

**Q: Is there support for batch RAW file processing?**
A: While the suite focuses on file management, metadata, and export workflows, it supports all file formats that Photo Mechanic can view and ingest, including RAW files. The batch renaming and metadata functions work seamlessly with RAW files.
